Что меняется относительно текущей ленты

1. Строка = пользователь, не сообщение — darklandsky и selec4 раньше занимали 4 отдельные карточки, теперь 2, каждая со счётчиком сообщений.
2. Правый клик убран целиком — feedback на сигнал теперь две обычные кнопки (✕ / ✓), видимые сразу, без tooltip и без жеста, который половина модераторов не знает.
3. Принадлежность кластеру — точка-маркер на свёрнутой строке и отдельная плашка при раскрытии, а не чип "участие в кластере" вперемешку с остальными сигналами.
4. «Доверять пользователю» — существующий эндпоинт /users/{id}/mark_safe, просто вынесен на уровень группы, а не только на экран «Доверенные зрители».
5. Свёрнутая строка не требует скролла глазами по чипам — ник, вердикт, превью, счётчик и время в одну строку фиксированной высоты; лента длиной 20 пользователей умещается в исходные 5-6 строк текущего дизайна.
